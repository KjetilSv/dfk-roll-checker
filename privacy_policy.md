# Privacy Policy — Kjetil'S Awesome Roll Checker

**Effective date:** 2026-03-11

## Summary
This extension does **not** collect, store, transmit or share any personal data.

## Data access
The extension uses the `activeTab` and `scripting` permissions solely to read visible game data from the active DeFi Kingdoms tab (`game.defikingdoms.com`) when the user clicks the button. The data is used only to calculate roll results displayed in the popup. Nothing is sent to any server.

## No analytics, no tracking
No analytics or tracking libraries are used. No network requests are made by this extension.

## Contact
If you have any questions, open an issue on the extension's repository or contact the developer.
